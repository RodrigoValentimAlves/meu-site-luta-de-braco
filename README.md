# Site Oficial Rodrigo Valentim Alves - Luta de Braço

Projeto completo com divisão por papéis: **Atleta**, **Técnico** e **Juiz**, com histórico detalhado de conquistas e mídia.

## Como importar no VS Code:
1. Extraia este arquivo `.zip`.
2. No **VS Code**, vá em `File > Open Folder...` e selecione a pasta extraída.
3. Clique em **"Go Live"** no canto inferior direito para rodar no navegador.
